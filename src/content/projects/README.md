# Projects

Add project entries as YAML files inside `es/` and `en/` subfolders. Example:

```yaml
lang: es
title: "Nombre del proyecto"
description: "Breve descripcion del proyecto."
order: 1
technologies:
  - "Astro"
  - "TypeScript"
url: "https://example.com"
repository: "https://github.com/user/repo"
featured: true
draft: false
```

Use `draft: true` to keep an entry as an unpublished example.
